# 🦷 LankaCare Dental Clinic — AI Web Application

> A modern AI-powered dental clinic web application developed as a portfolio project by **GET AI Agency**.

## 🚀 Project Overview

LankaCare Dental Clinic is a fictional dental clinic created as a **GET AI Agency portfolio demo**.

The project demonstrates how a modern web application can improve a clinic's digital presence, simplify appointment management, and provide patients with instant answers to common questions.

## 🎯 Problem

Many local healthcare clinics can face challenges such as:

- Lack of a professional online presence
- Difficulty finding service information
- Manual appointment handling
- Repetitive patient inquiries
- Time-consuming booking and schedule management

## 💡 GET AI Solution

We designed and developed a modern responsive web application with:

- 🤖 Gemini-powered AI assistant
- 📅 Online appointment booking
- 🦷 Interactive dental service directory
- 👨‍💼 Staff management dashboard
- 📆 Calendar integration architecture
- 📱 Responsive mobile experience
- 📍 Clinic location and contact information

## ✨ Key Features

### 🤖 AI Virtual Assistant

A Gemini-powered assistant designed to answer common questions about:

- Dental services
- Opening hours
- Location
- Indicative pricing
- Appointment process

The assistant is designed for FAQ-style support and should not replace professional medical advice.

### 📅 Appointment Booking

Patients can:

- Select a dental service
- Choose a preferred date
- Select an available time
- Enter contact information
- Submit an appointment request
- Receive a booking reference

### 🦷 Service Directory

The application provides categorized dental services with:

- Service descriptions
- Treatment categories
- Indicative pricing
- Duration information
- Booking actions

### 👨‍💼 Staff Management Portal

Clinic staff can view and manage appointment information through an internal dashboard.

### 📱 Responsive Design

The application is designed for:

- Desktop
- Tablet
- Mobile
